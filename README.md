# WDD 231 – Week 01 Course Home Page

Open `index.html` using Live Server. This is a static HTML/CSS/JavaScript project; no npm installation is required.

## Before submitting

1. Replace the general LinkedIn link in `index.html` with your actual LinkedIn profile URL.
2. Set `completed: true` **only** for courses you have passed in `scripts/course.js`.
3. Compare the array with the **exact official source**: https://byui-cse.github.io/wdd231-ww-course/week01/courses.js — the direct JavaScript file could not be fetched during preparation, so the six verified course codes, titles and credits are included without claiming the entire official object shape was copied.
4. Test mobile menu, course cards, filters and credit totals.
5. Test at 320px, 375px, 768px and 1200px; use DevTools, CSS Overview and Lighthouse in mobile and desktop incognito mode (95+ target for Accessibility, Best Practices and SEO).
6. Run the official assignment audit: https://byui-cse.github.io/wdd-audits/wdd231-w01-homepage.html
7. Commit/push into your **existing cloned** `wdd231` repository and verify GitHub Pages before submitting the live site URL to Canvas.

`chamber/index.html` and `final/index.html` belong to later assignments and are not included. Their navigation links will work after you create those projects.
